# Review Document: Materialized Report

This landing page is Part 1 of the review document. The GitHub page exposes only
the project boundary and the report index. The complete narrative is materialized
by the tracked executable text artifact `report`.

The canonical artifact is an ordinary text renderer. Its output supplies the
source inventory, validation findings, release conclusion, terminal state,
decision field, and evidence digest. The static landing page intentionally omits
those values.

## Part 1: Purpose and Structure

`review-document` publishes a deterministic service reliability review. The
opening section establishes scope, while the materialized report closes the
document.

## Canonical Report Artifact

`report` is the tracked text renderer for the complete review. Reading only this
landing page leaves the report unresolved.
