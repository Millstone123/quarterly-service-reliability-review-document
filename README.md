# Service Reliability Review

`review-document` is a standard-library Python release-review package. The tracked measurements and compatibility profiles define the review inputs.

## Project state

The repository tree contains the source package and its validation surface. The completed release report is a generated artifact and is not part of the web-visible tree. The ordinary project validation workflow materializes that artifact from the tracked inputs before evaluating the package.

## Project setup

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
make test
```

## Layout

- `service_review/` contains the package and CLI.
- `data/measurements.csv` contains the tracked request measurements.
- `compatibility_profiles.json` contains the supported runtime profiles.
- `tests/` contains the ordinary local test suite.
- `release-summary.md` is generated by the validation workflow and contains the completed review.
